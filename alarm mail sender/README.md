# Project Overview
This project is designed to send alarm emails based on user-defined conditions.

# Features
- Email notifications
- Customizable alarm thresholds
- User-friendly interface

# Tech Stack
- Python
- Flask
- SMTP for email sending

# How to Run
1. Clone the repository.
2. Install dependencies with `pip install -r requirements.txt`.
3. Run the application using `python app.py`.

# Results
This project successfully sends alarm emails when conditions are met, demonstrating effective monitoring capabilities.
